# Fleet Guardian Dashboards

## Dashboard 1: Fleet Operations Dashboard

Metrics:

- Active Trucks
- Total Trucks
- Active Drivers
- Shipment Updates
- Failed Shipments

Purpose:
Monitor overall fleet health and activity.

---

## Dashboard 2: API Performance Dashboard

Metrics:

- API Latency
- Request Throughput
- Error Rate
- Response Time

Purpose:
Track service performance and reliability.

---

## Dashboard 3: Infrastructure Dashboard

Metrics:

- CPU Usage
- Memory Usage
- Service Availability

Purpose:
Monitor infrastructure health.

---

## Dashboard 4: Incident Dashboard

Metrics:

- HTTP 500 Errors
- Shipment Delays
- Driver Traffic Spikes

Purpose:
Support incident investigation and troubleshooting.

---

## Future Splunk Observability Integration

The dashboards are designed for deployment in Splunk Observability Cloud using OpenTelemetry metrics, traces, and logs.
